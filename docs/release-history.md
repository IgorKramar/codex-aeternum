# Версии релизов

Автор: Igor Kramar.

Новая последовательность: **0.1.0 → 0.2.0 → 0.2.1 → 0.3.0**. До стабилизации публичного формата расширение книги и возможностей увеличивает minor, исправления — patch.

| Прежнее имя релиза | Актуальное имя | Тег исходников | JAR |
|---|---|---|---|
| 1.0.0 | 0.1.0 | v0.1.0 | codex-aeternum-0.1.0.jar |
| 2.0.0 | 0.2.0 | v0.2.0 | codex-aeternum-0.2.0.jar |
| 2.0.1 | 0.2.1 | v0.2.1 | codex-aeternum-0.2.1.jar |
| Рабочая версия 3.0.0 | 0.3.0 | v0.3.0 | codex-aeternum-0.3.0.jar |

Исторические релизы GitHub переименованы, приложения пересобраны из соответствующих исторических исходников с новой `mod_version`. Версия внутри `neoforge.mods.toml` проверена. Новые теги указывают на отдельные коммиты изменения версии; прежние теги сохранены как исторические ссылки. Номер сетевого протокола задаётся независимо от номера релиза.

## 0.3.0

Полная редакция книги: 1165 заданий (907 исходных ID сохранены, 54 производственных
проекта, 204 новые факультативные ветки), человеческие цели достижений, вступительный
экран и единое оформление. Подробности — в [отчёте о проверках](validation.md).
