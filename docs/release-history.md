# Версии релизов

Автор: Igor Kramar.

Последовательность: **0.1.0 → 0.2.0 → 0.2.1 → 0.3.0 → 0.4.0**. Что изменилось в каждой версии — в [CHANGELOG.md](../CHANGELOG.md). До стабилизации публичного формата расширение книги и возможностей увеличивает minor, исправления — patch.

Исторические релизы GitHub переименованы, приложения пересобраны из соответствующих исторических исходников с новой `mod_version`. Версия внутри `neoforge.mods.toml` проверена. Новые теги указывают на отдельные коммиты изменения версии; прежние теги сохранены как исторические ссылки. Номер сетевого протокола задаётся независимо от номера релиза.

## 0.3.0

Полная редакция книги: 1165 заданий (907 исходных ID сохранены, 54 производственных
проекта, 204 новые факультативные ветки), человеческие цели достижений, вступительный
экран и единое оформление. Подробности — в [отчёте о проверках](validation.md).

## 0.4.0

Настройки книги на обложке: порядок прохождения (строгий, только внутри карты, свободный —
хранится в прогрессе игрока на сервере), подсказки о предметах, уведомления, стартовый экран.
Подсказка при наведении на цель или награду показывает, как получить предмет: рецепты
и ингредиенты, с кого выпадает и где обитает, в каких сундуках лежит, из каких блоков
добывается, в каких биомах встречается (`tools/hints.py` строит индекс по JAR сборки);
для достижений — название и описание из самого мода. Все тексты книги прошли литературную
редакцию: без канцелярита, жаргона и однотипных оговорок. Сетевой протокол 3: клиент и сервер
должны быть одной версии.
