# Переработка Кодекса

Автор: Igor Kramar

## Цель
Связная обучающая книга с крупными картами производственных этапов, понятными целями и надёжным серверным прогрессом. Ориентир — насыщенные ветки GTNH, адаптированные к фактической сборке 1.21.1, без переноса рецептов из другой сборки.

## Области реализации
1. Компилятор книги: отделить загрузку, проверку, локализацию и запись. Проверять глобальные зависимости, циклы, типы целей, количества, локализацию. Ошибка не должна менять опубликованные JSON. Добавить режим проверки воспроизводимости и тесты.
2. Прогресс: альтернативные зависимости ANY вместе с обязательными ALL, корректная сдача ресурсов и синхронизация, выдача наград, сохранение и загрузка. Старые идентификаторы квестов и прогресс сохраняются.
3. Геймдизайн: объединить мелкие тематические главы в крупные карты без смены идентификаторов прогресса, связать этапы, исправить ложные развилки. Добавить производственные задачи с конкретной проверкой результата. Удалить заведомо неверные технические объяснения. Сверять предметы и рецепты с установленными jar.
4. Интерфейс: крупные карты этапов, читаемые связи, переходы к предпосылкам, адаптация панелей, обзор графа и масштабирование.
5. Проверка: Python regression suite, воспроизводимость ресурсов, Java build/tests; визуальная проверка при доступном игровом клиенте. Указать отдельно то, что проверяется только в игре.

## Условия качества
- Ни потерянных ссылок, ни циклов, ни совпадающих позиций на карте.
- Альтернативные пути действительно альтернативны; необязательная специализация не блокирует основной путь.
- Существующие globalId сохраняются для совместимости сохранений.
- Описание объясняет практический результат, условия работы и применение следующего этапа; получение предмета не выдаётся за автоматическую проверку работающей постройки.
- Генератор не маскирует ошибки и не оставляет ресурсы частично обновлёнными при ошибке валидации.
- Все изменения доступны локально для проверки; установка в игровой экземпляр — отдельное действие.
