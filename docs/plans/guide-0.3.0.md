# Кодекс 0.3.0 — руководство для новичка

Автор: Igor Kramar.

1. Версии: историческая схема 0.1.0 → 0.2.0 → 0.2.1 → 0.3.0. Имена файлов и документация согласованы; сетевой протокол версионируется отдельно.
2. Цели достижений содержат действие на выбранном языке, а не технический ID. Существующие ключи прогресса сохраняются.
3. Весь корпус: подробные, связные, полезные описания каждого квеста и введения в каждую главу, RU/EN. Полнота покрытия проверяется генератором.
4. Новые боковые цепочки объясняют дополнительные процессы, автоматизацию, диагностику и экспедиции. Они имеют конкретные входы, не блокируют обязательный путь и проверяются по реальному реестру.
5. При открытии: отдельная стартовая страница Codex Aethernum с логотипом, назначением книги, объяснением управления и переходом к карте/продолжению.
6. Единое оформление всех экранов: ночной синий атлас, бирюза, золото, светлый текст. Обложка, граф, оглавление, описание, обзор, кнопки и подсказки используют общую палитру.
7. Проверка: генератор/граф/переводы, Java-регрессии, сборка JDK21, запуск итогового JAR в отдельном экземпляре полной сборки, снимки стартового экрана и целей достижений.

Исполнение: native, внешние модели не назначены, конфигурация CE отсутствует. Авторство карт делегируется в отдельные каталоги; интеграция, код и полный прогон принадлежат основной сессии.
